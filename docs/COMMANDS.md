# Commands and permissions

## Commands

| Command | Description | Permission | Usage |
|---------|-------------|------------|-------|
| `/banner` | Quote and buy letter, number, symbol, or blank color banners | `` | `/<command> <text/confirm/cancel/colors/prices/help>` |

## Permissions

| Permission | Description | Default |
|------------|-------------|---------|
| `rootbanner.use` | Use /banner | `true` |
| `rootbanner.reload` | Reload root-banner.yml | `op` |
| `rootbanner.free` | Receive banners without paying Gold | `op` |
